# Koníčkovi webdesign

Statické portfolio. `index.html` je úvodní stránka, každý web klienta je
samostatná HTML stránka ve stejné složce.

| Stránka | Soubor |
| --- | --- |
| Portfolio | `index.html` |
| Manolo Café | `manolo.html` |
| VINCI Nail Bar | `vinci.html` |
| Oliver's Café | `olivers.html` |
| Dave's Barber Shop | `daves.html` |
| Lístek (květinářství) | `listek.html` |
| FK Vlčí Důl | `vlcidul.html`, `vlcidul-soupiska.html` |
| Monkey Coffee House | `monkey/index.html` |
| Projekty (na heslo) | `projekty.html` |

Obrázky jsou ve složce `img/`, loga v `loga/`.

## Spuštění lokálně

```bash
python -m http.server 8200
```

Potom otevřete <http://localhost:8200/>.
