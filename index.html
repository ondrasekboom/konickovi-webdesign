Jak spolupracujeme

Postup

Od prvního rozhovoru po spuštění. Průběžně vidíte, jak web vzniká.

  1. Rozhovor

    Zjistím, co děláte, pro koho, co má web umět a jakou máte představu.

  2. Nápad a návrh

    Najdeme jeden nápad, který web odliší od konkurence, a na něm stavím celý vzhled.

  3. Vývoj

    Zprovozním web, který funguje na mobilu i na počítači a dá se snadno upravovat.

  4. Spuštění

    Web vypustím do světa a pomůžu s úpravami, když se něco bude měnit.
